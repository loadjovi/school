# LINE 通知中心與收費核帳快速返回（LINE LAB）

> 後續調整：LAB 收費專案 DEMO 已移除，日常財務入口使用原「團服與活動」核帳流程；本文保留前次工具返回修正紀錄。
原因：工作首頁的 LINE／收費入口原本導向獨立 HTML，返回 `/` 會重新建立主程式、身分、學生名單與後台功能。一般頁簽則只切換已建立的工作區。

現在普通點擊兩項首頁入口時，使用各自獨立的工作區文件，保留原後台、已載入名單與待辦。返回只切換到工作首頁，不重設工具網址或自動重送請求；再次開啟同一個工具／活動保留草稿、正在處理的請求與結果。改開不同活動或切換學校／身分時會重新建立對應文件。

- 真實 `href` 保留；直接網址、修飾鍵、新分頁、下載及外部連結仍依原有方式操作。
- 收費入口維持 `feeCollections`，LINE 維持 `lineRoleMenus || lineAccount`，核帳及發送仍由原有 API 驗證，不變更金流或通知規則。
- 子頁隱藏重複頁首與 LAB 標籤，使用原後台的「返回工作首頁」；內容高度隨預覽、紀錄展開／收合調整。隱藏時保留最後有效高度。
- 訊息回傳必須同源、來自該工具 iframe、同學校、同登入身分，且返回只能由目前顯示的工具觸發。高度限制範圍；不接受任意返回網址。
- 從活動設定進入 LINE 時保留原活動文件，返回相同活動不重新載入表單。若使用者已切換到其他活動，只恢復已驗證的原活動識別與學校。
- 舊快取根目錄連結誤在工具內開啟完整平台時，會清除該工具文件並返回外層工作首頁，避免再次產生框中框。

測試：`tests/admin-service-return.test.mjs` 驗證父工作區切換、重複開啟只指定一次網址、名單物件保留、權限／身分隔離、活動返回及快取修復；`tests/school-service-frame.test.mjs` 驗證子頁橋接、獨立網址、修飾鍵、高度及同校活動。搭配既有通知、收費、活動返回與 iframe 回歸測試，沒有發送真實通知或異動金流資料。未量測實際裝置的返回秒數。
