# 第四階段｜團服收款與核帳

## 已確認規則
- 團 T：每位學生終身首件免費，第二件起每件 NT$400。
- A 團比賽服：自費購買／加購每套 NT$2,625（含稅）。
- 暫時使用幹部個人帳戶，未來切換學校帳戶。
- 僅本人付費訂單可查看匯款帳戶；回報末五碼後仍待財務核帳。

## 上線門檻
1. 後端查驗學生、學校、訂單與付款狀態；不可相信前端金額。
2. 先核對歷史團 T 已配發資料及尺寸，避免重複免費。
3. 帳戶資料僅財務管理員可設定，家長只在本人應付款訂單取得。
4. 收款帳戶變更保留歷史快照與稽核紀錄。
5. 匯款日期、金額、末五碼、核帳人與時間保留稽核紀錄。
6. 財務權限必須經授權，普通管理員不得逕行確認收款。
7. 校外活動需二階段確認，期末聚餐需顯示匯款帳戶與末五碼。
8. 在 PR #22 預覽環境測試，未驗收前不合併 main。

## 全部付費項目共用的付款回報規則（2026-10-12 確認）
- 所有家長付費交易（團 T 加購、A 團比賽服自費／加購、期末聚餐、校外活動）均須回報匯款帳號後五碼、匯款日期及應繳金額，供幹部核帳；免費交易不要求後五碼。
- 家長匯款回報後一律標示「已回報匯款／待幹部核帳」，不能自動認定「已繳費」。
- 幹部需能按活動、學生、家長、金額、匯款日期、後五碼查詢與註記，確認入帳才改為「已確認收款」。
- 同樣後五碼可能重複，必須比對銀行實際入帳日期、金額與其他資料；不可單憑後五碼核帳。
- 期末聚餐於報名付款階段提供收款帳戶及後五碼欄位；校外活動於第二階段確認費用後才提供付款資訊及後五碼欄位。
- 禁止在公開活動列表或非本人訂單洩露幹部完整銀行帳號；付款資料及核帳異動需留存稽核紀錄。
