# 第四階段｜團服收款與核帳

## 已確認規則
- 團 T：每位學生終身首件免費，第二件起每件 NT$400。
- A 團比賽服：自費購買／加購每套 NT$2,625（含稅）。
- 暫時使用幹部個人帳戶，未來切換學校帳戶。
- 僅本人付費訂單可查看匯款帳戶；回報末五碼後仍待財務核帳。

## 上線門檻
1. 後端查驗學生、學校、訂單與付款狀態；不可相信前端金額。
2. 先核對歷史團 T 已配發資料及尺寸，避免重複免費。
3. 帳戶資料僅財務管理員可設定，家長只在本人應付款訂單取得。
4. 收款帳戶變更保留歷史快照與稽核紀錄。
5. 匯款日期、金額、末五碼、核帳人與時間保留稽核紀錄。
6. 財務權限必須經授權，普通管理員不得逕行確認收款。
7. 校外活動需二階段確認，期末聚餐需顯示匯款帳戶與末五碼。
8. 在 PR #22 預覽環境測試，未驗收前不合併 main。
