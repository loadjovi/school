# LINE LAB 正式整合｜2026-11-24

正式移轉以已驗證 LINE LAB `789fc91fffd46586b11df6c6277c202d9f22b0a0` 為基礎，合入正式區 `32cd760ec244d899096a8bb85f512de19282b274` 已有的比賽服歷史領用、公費分類與個課誤約取消修正。發布只更新程式，不複製 LAB Storage、帳號、憑證、群組或測試資料。

## 移轉前修正

- 補退費、LINE 優先通知、教師日常鼓勵與個課練習進度在正式環境使用明確的正式政策；舊 LAB 仍抑制，LINE LAB 需建置開關與獨立 Storage 檢查。
- 通知連結使用各校設定；只有原預設學校可沿用既有正式網址。正式通知不帶 LAB 標記。個課 Email 開關、各校 Email 停用與通知去重保留。
- Messaging API 與 LINE Login 分開：既有預設學校官方帳號可唯讀驗證現用 bot 並沿用舊群組及有效個人收件綁定，不建立新登入身分、不轉移權限、不替其他學校套用舊憑證。LINE Login／互動評鑑仍要求該校已驗證 Login 設定。
- 幹部需求到貨建立庫存保留，實際發放與防重複帳本同筆交易。採購及領用兩入口共用同筆交付；同步失敗可重試，歷史完成資料不補扣。
- 既有正式比賽服補登與取消個課誤約功能保留；財務只供已授權人員使用。收費專案 DEMO 在各環境停用。
- 付費活動開放通知由固定 main 工作流程以短效 OIDC 身分約每五分鐘輪詢到期事件；可保留既有每分鐘 Logic App。兩者共用派送去重，不手動觸發真實通知作為驗證。

## 發布與驗證

1. 全部 `tests/*.test.mjs`、`api/test/*.test.mjs`，Python LAB 隔離與來源一致性、所有前後端模組語法及工作流程語法通過。
2. 相同來源先部署至獨立 LINE LAB，核對部署及公開檔案。
3. 以預期正式 SHA 做原子更新，正式 workflow 僅發布原始 app／api；不使用 LAB 建置產物。
4. 確認正式靜態檔案與發布來源一致、API 可用、正式頁面無 LAB 標記、未授權財務及派送 API 拒絕。登入角色操作仍由正式使用者既有 session 進行，驗證不執行付款、發放或真實推播。

## 既有外部設定與後續改善

發布前正式 `/api/line/login-schools` 回傳空清單：新版 LINE 直接登入與 LINE 互動評鑑仍需由 Global 管理中心完成正式學校的 Login Channel／回呼設定。原 Google 登入及經驗證的 Messaging 綁定可繼續使用，發布不會以 LAB 憑證自動啟用。

幹部需求「直接分配既有庫存」保留為後續改善；本版沿用原幹部採購到貨流程，不允許未到貨或零庫存強制發放。家長新購的庫存優先分流已包含在本次移轉。
