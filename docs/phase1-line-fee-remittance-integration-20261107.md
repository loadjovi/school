# 第一階段完成說明｜LINE 帳號綁定、收費專案、匯款核帳

## 本階段範圍

已整合以下三項，適用於「團 T」與「期末聚餐」：

1. 家長以平台 Google 帳號登入後，產生一次性 6 位碼，於 LINE 官方帳號一對一聊天室輸入 `#綁定帳號 123456` 完成個人 LINE 綁定。
2. 後台建立收費專案，選擇既有幹部收款帳戶，再同步既有團 T 申請或期末聚餐報名資料。
3. 家長回報匯款日期、正確金額與匯出帳號末五碼；指定財務人員比對銀行入帳後確認，或退回家長補正。

個人 LINE 綁定定位為家長通知服務的共同入口，方便後續逐步整合弦樂團課程、活動及其他重要提醒；團 T、期末餐費與匯款核帳通知是第一階段先啟用的應用情境，不代表家長登入後一定有待繳費用。

收費專案不另建一套付款結果。家長回報、財務核帳及退回補正都直接更新原團 T／期末聚餐紀錄，因此採購、活動名單與財務畫面會看到相同狀態。

## 操作流程

### 管理員／財務

1. 從工作首頁進入「收費專案與匯款核帳」。
2. 建立草稿：選擇團 T 或期末聚餐、專案名稱、期限與收款帳戶。
3. 按「同步收費對象」。
4. 檢查筆數與應收金額。
5. 由已指派財務權限的人員按「開放繳費」。
6. 對待核帳資料逐筆比對銀行紀錄：
   - 資料正確：填銀行實際入帳日與核帳備註，確認入帳。
   - 查無款項或資料不符：填補正原因，退回家長重新回報。

### 家長

1. 從首頁進入「LINE 通知與家長服務」。
2. 可先開啟 LINE 個人通知；綁定碼只可在官方帳號的一對一聊天室使用。
3. 查看本人家庭的專案、應繳金額、期限及收款帳戶。
4. 完成匯款後填寫匯款日與末五碼；金額由系統鎖定，不可自行改寫。
5. 等待財務核帳。核帳完成或資料退回補正時，已綁定者會收到 LINE 私訊。

## 權限與資料保護

- 草稿可由學校管理員建立；只有被指派財務權限的人員能開放收費與核帳。
- 家長只能讀取與自己 Email／已授權學生關聯的款項。
- 個人付款資料不發到 LINE 群組；只私訊已綁定的本人帳號。
- 綁定碼 15 分鐘失效、只可使用一次，資料庫只保存雜湊值。
- 平台只收匯出帳號末五碼，不收完整匯出帳號。
- 建立、同步、開放、回報、核帳與退回補正均保留稽核紀錄。

## 部署設定

沿用既有：

- `LINE_CHANNEL_SECRET`
- `LINE_CHANNEL_ACCESS_TOKEN`
- `STORAGE_CONNECTION_STRING`

可選設定：

- `LINE_OFFICIAL_ACCOUNT_URL`：家長頁「開啟 LINE 官方帳號」按鈕網址。
- `LINE_ACCOUNT_BINDING_TABLE`、`FEE_PROJECT_TABLE`、`FEE_PROJECT_CHARGE_TABLE`、`FEE_AUDIT_TABLE`：如未設定，系統會使用預設表名並自動建立。

## 驗收清單

- [ ] 家長產生綁定碼，在官方帳號私訊後顯示綁定成功。
- [ ] 同一綁定碼無法重複使用；群組內輸入帳號綁定碼會被拒絕。
- [ ] 幹部建立團 T 專案並同步，筆數與既有自費團 T 需求一致。
- [ ] 幹部建立期末聚餐專案並同步，筆數與該活動報名一致。
- [ ] 普通管理員不能開放專案或確認入帳。
- [ ] 家長只看到本人家庭款項；回報後狀態為「已回報，待核帳」。
- [ ] 財務確認後，原訂單與收費專案同時顯示「已確認入帳」。
- [ ] 退回補正後，家長可重新回報，前次資料仍保留於稽核歷程。
- [ ] 已綁定 LINE 的家長收到核帳／補正私訊；群組沒有個人付款資訊。

## 首次加入好友與綁定補充（PR #83 後續修正）

- 家長尚未加入 LINE 官方帳號時，先從「加入／開啟 LINE 官方帳號」進入加入好友流程。
- 官方帳號連結由 `LINE_OFFICIAL_ACCOUNT_URL` 提供；僅接受 LINE 官方加入好友網址（`https://line.me/R/ti/p/@...` 或 `https://lin.ee/...`）。
- **若未設定連結，前端顯示明確管理員設定提示，不假裝入口已完成**。
- 加入好友後從平台產生一次性碼，複製 **完整指令** `#綁定帳號 123456`，在 LINE 官方帳號一對一聊天室傳送。單獨輸入六位數字不會被現有 Webhook 接受。
- LINE 回覆綁定完成後，回到平台點「我已傳送，確認綁定狀態」重新讀取後端綁定結果。
- 加好友連結僅是導引，不會自動完成身分綁定。Webhook 必須啟用並可被 LINE 存取。
- 目前僅完成靜態程式／單元驗證；真實 LINE 與 Azure Table E2E 需在隔離的測試環境以測試帳號驗收。

### E2E 驗收
1. 全新家長帳號、尚未加好友：點連結加入官方帳號，再傳送完整指令，確認成功。
2. 在 LINE 群組貼綁定指令：拒絕綁定。
3. 過期、重複使用的綁定碼：拒絕綁定。
4. 已有其他家長綁定的 LINE User ID：拒絕跨帳號綁定。
5. 家長在平台重新查詢綁定狀態：顯示成功。
6. 未設定 `LINE_OFFICIAL_ACCOUNT_URL`：顯示警告、不顯示加入連結。
