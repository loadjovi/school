# 後台老師 Gmail 與 LINE 配對狀態

學校管理員可在「老師帳號管理」的每張老師卡片直接查看 Gmail 與 LINE 配對結果，無須借用老師帳號登入。

## 顯示規則

- 已配對：目前 Google 索引、LINE 帳號與正式 email 索引的同校、官方帳號、Google 身分、Gmail、LINE 身分及正式家長識別均一致。
- 未完成配對：沒有查到可確認的現行 Gmail／LINE 配對；僅完成 LINE 授權但尚未確認綁定，仍不列為已配對。
- 配對需確認：查到的綁定資訊不完整或不一致。
- 學校 LINE 尚未設定：目前學校無可驗證的 LINE Login 設定。
- 暫時無法確認：查詢發生錯誤，不能據此判定老師尚未綁定。

已配對時顯示 LINE 名稱、綁定時間與獨立的官方帳號好友紀錄。好友資料是上次確認結果；Gmail／LINE 已配對不代表官方帳號目前可發送通知，也不代表通知已送達。

## 資料與權限

老師目錄 API 沿用學校管理員與目前學校的存取範圍，新增安全摘要 `lineBinding`。不回傳 LINE user ID、Google sub、憑證或 OAuth 確認資料。狀態查詢只讀取目前平台索引與好友紀錄，不呼叫 LINE 個人資料 API，不新增、恢復、解除綁定或傳送通知。

先用 LINE 建帳再配對 Gmail 的同校帳號，沿用既有共用綁定查詢並重新檢查現行索引。舊版僅能投遞通知的相容綁定，不當作已完成 Gmail／LINE 配對的證明。

「更新 LINE 綁定狀態」只重新讀取資料；老師啟用狀態、帳號類型、授課學生與未儲存的編輯內容保持原樣。切換登入身分或學校後，舊請求不能更新新畫面。

本功能驗證程式流程與隔離案例，不代表已逐一核對正式老師的私人帳號，也沒有代替老師重新登入、綁定或發送測試通知。

- 變更檔案 JavaScript 語法及差異格式檢查通過。
