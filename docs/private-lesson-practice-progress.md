# 個課練習建議與自主練習打卡

本次提供於獨立 LINE LAB，正式平台尚未啟用新通知。

- 家長在「自主打卡」點選個課老師的建議，下方「今天練什麼」自動帶入「有練習：建議內容」，練習類型切換為「個課老師建議」。切換目標或選「這次練習其他內容」時保留家長自行輸入的文字。
- 點選本身不建立紀錄。送出打卡後，儲存學生、個課、老師與建議文字的對應；沿用原有 14 天目標使用期間及每日 20 分鐘達標規則。老師已修改建議時，要求重新整理再選擇，避免記到另一項功課。
- 成功儲存後通知原個課老師，提供學生、練習日期、分鐘、建議與練習內容。LINE 優先；未受理者依既有 LAB 規則改寄 Email。儲存不因通知失敗而回滾；相同打卡重送使用同一個通知事件，避免重複發送。
- 老師在「個別課 → 老師個課處理與紀錄」展開該堂課，再展開「查看課後練習進度」，可查看各項建議的次數、分鐘、最近日期與逐次打卡。通知連結指定同一學生、同一堂課。僅更新此進度區塊，不自動重繪老師尚未儲存的上課內容。
- GET `/api/private-lesson-practice` 依登入學校、學生綁定及該堂原老師限制讀取；私課專任老師無須取得全團練習權限。已移除的老師綁定不再接收通知。學號別名合併去重，不跨學校查詢或發送。
- 「有練習紀錄」表示家長已回報，不代表老師評量通過或已熟練。老師重寫建議後，舊紀錄保留原文字，不計入新建議的次數。

驗證使用實際打卡與老師查詢處理器、共用 LINE 優先通知程式及記憶體儲存／通訊替身；涵蓋送出後通知、重送去重、Email 備援、通知失敗仍保留打卡、權限／學校界線、學號別名、舊建議快照、原計分規則及前端保留草稿。測試不發送真實 LINE 或 Email。
