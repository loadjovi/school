# 家長 LINE 通知收件資格

通知中心選擇「家長／老師 → 家長 → 所有團別」時，所有團別是指本校目前學生團別，不是所有 LINE 官方帳號好友。這條個人通知流程不查詢好友清單，也不使用官方帳號廣播。

家長名單由本校的學生關係產生，再比對同校官方帳號的有效 LINE 收件綁定。同一 LINE 帳號符合多名學生時只列一次；未綁 LINE 的核准家長不會進入 LINE 推播目標。

## 查核與修正

一般剛加好友、僅完成 LINE／Gmail 配對、沒有學生關係或尚在等待審核的帳號，原本不會列入。但原名單解析器只取 status=active 的學生關係，沒有核對該關係引用的審核紀錄。如果審核流程先寫入 active 關係、後續核准紀錄寫入失敗，可能留下 active 關係與 pending 審核不一致的狀態。

公告名單改共用核准通知既有的唯讀學生核准證明。必須同時符合：

- 本校、此家長、此正式學生的關係仍為 active。
- 正式學生主檔存在且在團；不以同名比對把停用學生轉成另一名學生。
- 若關係引用 registrationId，該審核紀錄必須存在、屬於同校同家長同學生，且狀態為 approved。
- 沒有 registrationId 的管理員自綁及既有正式 active 關係繼續有效；不以靜態設定或模糊 alias 新增公告資格。
- 同一 LINE 帳號保留歷史登入別名時，仍須由目前的正式家長身分具有所選團別內的有效核准關係。只有舊別名的關係不能讓已失去家長資格的帳號進入個人推播或備援 Email 名單；老師角色另依有效老師名冊判定。

核准證明只讀取目前資料，不會核准申請、建立學生關係、發送核准卡或修改 LINE 綁定。審核或關係查核失敗時，不將該帳號視為合格收件者。

預覽與確認發送都重新計算名單。有效收件名單、團別、內容或群組目標改變後，原預覽會失效，必須重新預覽。

## 適用範圍

上述規則適用於通知中心的家長個人訊息。勾選學校／幹部群組或活動志工群組時，訊息會發至該群組，群內成員均可看到。官方帳號公開活動推廣、加入好友的歡迎訊息或帳號綁定確認，也不是這條家長學生通知的收件流程。

查核及回歸測試使用隔離資料與模擬 LINE 發送，沒有向真人家長寄送測試訊息，也沒有修改正式家長或學生資料。測試重現程式邊界，不代表正式資料庫中已發生相同的不一致狀態。
