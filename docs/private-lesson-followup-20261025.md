# 學期成績總覽：個課老師與待資料追蹤

學校管理員於「工作首頁 → 學期成績總覽」可查看每位在團學生的個課老師，並以老師或個課狀態篩選、匯出 CSV。

- 「已綁定」來自同校啟用老師的 privateStudentIds；「紀錄老師」來自所選計分月份的實際個課紀錄，兩者分開標示。未綁定不代表學生一定沒有在外上個課，需由學校確認。
- 「模式一｜個課待資料」保留原本模式判斷，篩出最後 5 分尚無資料的學生；其餘追蹤條件包括尚無個課紀錄、未綁定、待老師登記完課、待家長確認及完課有疑義。
- 計分月份沿用原規則：上學期 10～12 月、下學期 2～5 月。9 月試行資料不會被當成正式月份紀錄。未到日期的預約單獨顯示，不列完課。
- 「計分月份完課」直接使用原成績 API 的 privateLessonCompleted；待家長確認是作業狀態，不重算成績。老師已登記完課的計分規則沿用既有行為。
- 新 GET /api/admin-private-lesson-followup 僅同校管理員可讀，依學號別名比對及去重，回應 no-store。無新增／修改老師綁定、個課紀錄、成績或寄信行為。
- 追蹤資料讀取失敗時顯示錯誤，成績仍可查看；匯出暫停，避免將讀取失敗誤報為未綁定。
- 桌面表格及手機卡片均顯示老師、狀態、計分完課堂數及最近個課紀錄日期。CSV 依目前篩選附帶同一組資訊。

驗證：私課追蹤純邏輯、管理員權限／租戶界線、別名去重、正式月份、預約與完課狀態、前端篩選與 HTML 跳脫，以及既有成績頁回歸測試。
