# LAB 收費專案 DEMO 已移除

「LAB 收費專案驗證（DEMO）」已從「更多」移除，同時移除 DEMO 標題、建資料按鈕、建立虛構帳戶／報名的工具程式，以及 LAB 建置中的 fixture 安裝步驟。

LINE LAB 的收費專案功能關閉，即使舊環境仍有 `FEE_COLLECTIONS_ENABLED=true`，也不會再從該 LAB 的專案 API 讀寫資料。首頁與家長端依此功能狀態不顯示獨立專案入口。既有測試紀錄保留，不執行資料刪除。

日常財務核帳維持「財務核帳 → 團服與活動」原流程，涵蓋團 T、比賽服、活動、幹部／志工及補退款、庫存與採購。財務權限維持原有驗證。

舊 DEMO 開關曾同時啟用 LINE 付款通知，現拆為獨立的 LAB 付款通知開關，保留核准待匯款、財務匯款回報與家長入帳確認通知；不得跨學校或套用至正式環境。LINE 帳號頁共用的 `fee-collections.js` 保留帳號功能，不移除此必要相依檔案。

驗證包括專案關閉時 API 在讀取資料或解析寫入前回傳停用結果、原核帳捷徑及權限、LINE 付款通知相容、其他學校與環境隔離、LINE 帳號綁定及建置不再包含 DEMO fixture。
