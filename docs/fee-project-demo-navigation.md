# 收費專案驗證與實際財務流程分開（LINE LAB）

核對結果：`fee-collections.html` 是新增的收費專案模組，不是原有財務入口。LINE LAB 建置會強制為預設學校開啟專案驗證並安裝虛構資料建立功能；一般建置則依每校 `FEE_COLLECTIONS_ENABLED` 設定啟用。不能由此推斷正式站的環境設定。

此模組有 API，專案關聯另存，但繳費及核帳會寫回原團服／家庭活動的付款狀態，並非無作用的展示。其 VERIFY 尚未包含原核帳流程中的團 T 庫存分配，因此不應作為目前正常作業的統一入口。

本次只調整 LAB 的入口及標示，不變更既有 API、資料或付款狀態：

- LINE LAB 主頁加上專案驗證標記。一般管理員首頁與家長帳號工具不再顯示 DEMO 收費專案入口。
- 首頁改提供「財務核帳」捷徑，僅 `financeVerifier` 顯示，直接打開原有 `uniform-event-admin.html?embedded=school&task=finance`。團 T、比賽服、活動及幹部／志工沿用原核帳、補退款、庫存及採購流程。
- 測試模組保留在「更多 → LAB 收費專案驗證（DEMO）」，僅具財務權限且已開啟專案功能的管理員顯示／開啟。
- 測試頁面在資料載入前即清楚顯示 DEMO 標題，固定說明不被暫時狀態覆蓋。虛構資料仍須手動建立。
- 非 DEMO 建置的既有專案入口與每校開關維持原行為；LINE 帳號專頁不受 DEMO 標示影響。

驗證包括首頁與家長入口隱藏、原核帳路由與財務權限、DEMO 模式權限及返回、載入前／載入後標示、非 DEMO／帳號專頁相容與建置隔離。本次未操作真實付款或寄送通知，也不刪除現有測試資料。
