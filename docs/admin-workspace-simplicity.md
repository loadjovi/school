# 學校後台：工作首頁與穩定載入（LINE LAB）

首頁先列待辦，再列「常用工作」與「查詢與管理」。出勤、團服、財務核帳與 LINE 使用相同尺寸的入口；個課、學生、課表、帳號、成績集中管理。新手說明收合，子頁保留返回工作首頁。等待家長匯款與可立即處理的審核分開呈現。

財務核帳入口由 `financeVerifier` 與原有 API 驗證，LINE 入口維持 `lineRoleMenus || lineAccount`。LAB 收費專案 DEMO 已移除。既有 API、申請／財務／採購狀態、iframe 返回與活動連結不變。自己的 LINE 綁定移至「更多」。

手機底部維持單一三欄導覽並預留安全距離；小螢幕工作卡改為單欄，字級及鍵盤焦點保持清楚。樣式僅調整學校後台，其他角色維持既有版面。

登入確認管理員身分後，同時載入必要名單與預載後台程式；在資料及功能完成前顯示單一穩定載入畫面，避免舊 Dashboard 與附加面板閃現。相同載入畫面不重建 DOM。失敗時保留重試入口。

老師名單與家長綁定的背景讀取不再重複讀取核心名單或重畫整頁；收到資料時只更新相關區域。背景資料與核心名單先後抵達皆會套用正確關係，切換學校／身分後的舊回覆不寫回新畫面。資料未載入不顯示為確定的 0。

驗證：首頁工作與權限、真實連結、服務卡只移動一次、待辦／等待狀態、手機導覽、載入先後順序、重複讀取、背景更新、失敗重試及租戶切換以自動測試驗證。另執行完整功能測試、LAB 隔離與建置語法檢查，部署後比對線上前端檔案與 readiness。沒有以真實帳號操作或量測實際登入秒數；不宣稱固定載入時間。

財務核帳已獨立為財務專屬工作區；設定、核帳與通知集中管理，團服與活動維持一般作業。詳見 finance-workspace-separation.md。

最新導覽為「工作首頁／操作紀錄／平台設定」；更多頁移除，登出回到頁首右上角。個人 LINE 綁定已整合通知中心，詳見 admin-navigation-line-account.md。
