# 日常鼓勵同步家長通知（LINE LAB）

老師按「儲存鼓勵回饋」後，先保存原有每日回饋，再通知該學生在同一學校的有效家長綁定。訊息包含學生姓名、老師姓名、鼓勵圖示、選填留言與回饋日期；不修改自主練習紀錄或任何成績。

- 每位家長各自依 LINE 優先規則投遞；LINE API 受理後不寄 Email。未綁定或 LINE 未受理才改寄 Email。
- 沿用同一老師、學生、台灣日期一筆回饋。每日相同月份、圖示與留言共用持久投遞識別，重複儲存或同時送出不重複通知；內容修改後通知新內容。當日改回先前已通知的相同內容不重發。
- 使用伺服器的老師身分與學生家長關係，不接受前端指定收件者。學生舊識別碼透過既有同校別名對應；其他學校、其他學生、停用綁定與退團學生不通知。
- 發送前逐一重查回饋仍為同一內容、學生仍在團、家長綁定仍有效；被更新或刪除的舊回饋停止發送。
- 通知失敗不撤銷回饋。畫面顯示實際投遞狀態並保留留言供重試；持久紀錄已受理的家長不重送。結果不明時不自動重發。
- 僅 LINE LAB 建置啟用，正式環境不啟用。API 受理不等於實際讀取訊息。

`tests/practice-feedback-notification.test.mjs` 使用真實 API handler、通知模組與共用投遞器，搭配記憶體資料表及假的 LINE／Email 傳輸；驗證雙家長、別名、租戶隔離、重複／並行儲存、修改與重試、權限、失效綁定、過期回饋、成績不變及畫面狀態。測試不發送真實通知。
