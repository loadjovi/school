# 團服與活動管理模組：第一階段

本分支為**非正式環境**的第一階段資料與規則實作；尚未接入家長頁面、學校後台、Azure Functions 或 Table Storage，不能視為已上線。

- `app/uniform-event-rules.js`：一般團服尺寸、首次免費資格判斷、庫存與採購建議、A 團 15 人比賽服初始化參考資料、活動費用試算。
- 一般團服歷史資料尚未提供：既有學生一律先標記待確認；不得把空白歷史視為可免費領取。
- A 團名單僅作為匹配參考，不含 studentId，**不可依姓名直接寫入正式學生主檔**。
- 比賽服 8 租借、4 買斷、3 待確認；不推定付款或實際交付。
- 一般團服首次免費一件、加購 400 元、製作至少 10 件；庫存先配發。
- 校外教學／期末聚餐每場活動獨立設定日期、地點、費用與陪同規則。
- 正式接入前：確認 Azure Table schema、權限 API、schoolId 驗證、交易／併發、盤點資料及歷史領用匯入，再以 PR 審核。

待辦：API 持久化、角色權限、家長 UI、管理員 UI、完整測試、部署。
