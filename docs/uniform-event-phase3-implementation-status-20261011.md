## 收費規則
- 校外教學：團員、陪同成人皆需付費；額外非團員兒童依活動費率。
- 期末聚餐：團員免費但計人數；成人及非團員兒童依活動費率。
- 同家庭多名團員只需至少一位陪同成人，成人只計一次。
- 報名成功才計入人數；家長回報匯款不代表財務核實。
