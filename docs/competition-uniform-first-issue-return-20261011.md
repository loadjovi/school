# A 團比賽服公發、第二套自費與回收入庫（2026-10-11）

## 已確認
- 第一次領用由家長自由選擇「免費公發」或「自費購買」，不強迫使用公發庫存；不應再以舊的「租借／買斷」欄位推定首次收費或所有權。
- 第二套起（包含因長高換尺寸或同尺寸再領）一律由學生家長自費，現行每套 NT$2,625；不提供免費換尺寸。自費時原公發服必須送洗、繳回，並登記原款式（男／女）、原尺寸與學生。
- 目前唯一確認的**現有可用庫存**：男款 M 號 1 件。其他尺寸尚未確認，應顯示「待盤點／待替換繳回」，不可當作 0 件。
- 學生正在使用的公發服屬於「在外領用」，不屬於可用庫存。學生替換歸還後，仍須送洗與驗收合格才能列入可用庫存。

## 建議資料與狀態
- 發放紀錄：schoolId、studentId、issueSequence、issuedStyle、issuedSize、issuedAt、issuedBy、source（SCHOOL_ISSUED／SELF_PAID）、原公發服歸還義務與交易關聯。
- 回收紀錄：studentId、原公發服款式與尺寸、退回日期、接收幹部／老師、送洗／洗畢日期、驗收人、入庫日期、資產識別碼、備註、稽核。
- 回收狀態：待繳回 → 已繳回待送洗 → 已送洗待驗收 → 驗收合格待入庫 → 已入庫；損壞不可用另行處理。
- 退回後必須以**原公發服**尺寸入庫，而非新買尺寸。重複退回或重複入庫需以唯一交易 ID 防止。
- 目前 A 團 15 人舊展示名單有「租借／買斷／待確認」，是歷史登記，不能直接解釋為第一套自費或已付款；待逐人核對後遷移。

## 實作狀態
- PR #22 新增管理員頁面的公發規則、已確認男 M 一件庫存展示與歸還流程示意。
- **尚未**將男 M 1 件寫入 Azure 庫存、也未串接學生公發／自費交易、清洗驗收、庫存入帳及稽核。不可當成已完成實際入庫。

## 2026-10-11 補充確認：長高換尺寸
- 學生因長高需要更換尺寸，視同領用第二套（或後續套數），須自費 NT$2,625；不得以「尺寸交換」繞過自費規則。
- 新尺寸與原公發服尺寸需分別記錄；原公發服送洗、繳回、驗收後依原尺寸入庫。
- 已自費取得之服裝若再次更換，依後續自費規則辦理；不得自動要求歸還家長已購買並持有的服裝。原公發服如仍未歸還，歸還義務持續存在。

## 2026-10-11 最終確認：首套來源、資產所有權與歸還義務
- 首套如家長選擇弦樂團免費公發，依學生所需男／女款與尺寸，**先查詢已驗收合格的可用庫存**。有符合款式尺寸的可用庫存，優先從庫存發放並扣除可用量；沒有符合庫存則由弦樂團新購後公發，須登記採購與資產來源。
- 無論首套來自既有庫存或新購，只要是弦樂團公發，所有權均屬弦樂團，學生未來退團、畢業、換尺寸或改為自費持有時，皆須將公發服送洗、繳回，完成尺寸核對與驗收後才能重新入可用庫存。
- 第二套起（包括因長高換尺寸）為家長自費，屬家長所有，不需繳回；不得將自費服列入公發服回收清單，也不得因再購而要求歸還已自費服。
- 若學生仍持有未繳回的公發服，即使已另購自費服，原公發服的歸還義務仍持續存在。
- 庫存來源至少分為 `EXISTING_STOCK` 與 `NEW_PURCHASE`；所有權至少分為 `ORCHESTRA` 與 `FAMILY`；歸還義務依所有權判斷，不依新舊或購買順序猜測。
- 正式系統應以學生 ID 與公發資產 ID 關聯發放／送洗／歸還／驗收／入庫紀錄，保留時間及操作人員，並防止重複扣庫存或重複入庫。

## 2026-10-11 修正：首次可自由選擇自費
- 首次申請應提供家長兩種選項：**免費公發（弦樂團資產，需洗淨歸還）**、**自費購買（NT$2,625，家長所有，無需歸還）**。
- 家長即使遇到符合尺寸的公發庫存，仍可選擇自費購買；不得強制公發。
- 選擇免費公發才依符合款式與尺寸的可用庫存優先發放；無庫存由弦樂團新購公發。
- 選擇自費不扣公發庫存、不產生公發歸還義務；後續自費加購亦同。
- 已領公發服而再購自費服，原公發服仍須送洗歸還並經驗收入庫；不可把自費服當作公發資產。
