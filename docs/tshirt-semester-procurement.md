# 團 T 本學期採購總表

入口：學校後台 → 團服與活動 → 團 T → 採購總表。

整合在團學生首次公費、學生加購、幹部首次公費、幹部自費加購、志工自費加購。學生補登原有團 T 尺寸不構成加購；志工借用及送洗不自動形成新購需求。首次公費每人一件，已交付但尚未家長確認者不再採購。退團學生不列入目前需求。

本學期預設依台北日期判定：上學期 8/1 至翌年 2/1 前，下學期 2/1 至 8/1 前。加購以申請建立日期歸期，較早學期未結案需求另外併入並標示。首次需求以目前在團名冊為基準，查閱舊學期不代表當時名冊快照。

各尺寸規劃：尚待供應 − 正式可用庫存 − 已採購備貨待到貨，最低為零。庫存可用數為 onHand − reserved − unavailable。缺少庫存資料不等於零。待填尺寸列入需求總量與明細，但不能分配到採購尺碼。另加備貨是本次頁面的試算值，匯出可留存，不會自動形成訂單；重新開頁清除。

完整 CSV 包含總計、各尺寸、需求名單、未完成事項及志工借用；廠商版只保留總計與尺寸，不提供姓名或學生 ID。兩版都採 UTF-8 BOM 並防範 CSV 公式注入。缺少任一必要來源時，清空統計並停用匯出，不以舊數據或零件數誤導採購。

## 幹部／志工需求

在採購總表或幹部／志工入口登記。以已綁定家長帳號識別，包含本人姓名、關聯學生、類別、學期、尺寸、件數、備註。幹部首次公費的終身資格以家長帳號去重，不因有兩位孩子而增加。既有領用／借用紀錄仍有效；新增需求不會直接發放、入庫或扣庫存。

自費款項依後端現價計算，初始待財務核帳。只有具有 financeVerifier 權限者能確認入帳，必須提供實際日期、與應繳一致的金額、末五碼及核帳說明。未核帳不能標記已採購。進度為已確認 → 已採購 → 已到貨 → 已處理完成；實際入庫與發放依原流程另行登記。取消僅限未下單需求，且須說明。所有異動保留稽核及 etag 併發檢查。

沿用已部署的 `/api/uniform-events/parent-loans` 路由，以 `?view=procurement` 取得新增需求，另存 `TenantTshirtStaffDemand`，依認證學校隔離；一般領用／借還回應保持原狀。新增 action 為 ADD_DEMAND、VERIFY_DEMAND_PAYMENT、UPDATE_DEMAND_STATUS。只有學校管理員可使用，非財務人員不能取得銀行核帳細節。
