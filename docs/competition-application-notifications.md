# A 團比賽服申請通知補正

自費買斷沿用既有流程：家長送出後直接建立「已核准／待家長匯款」，不另外增加校方審核步驟。原通知與學校首頁只辨認 `PENDING`，因此漏掉買斷申請。

- 家長新送出買斷申請時，也發送幹部待辦通知，內容明確標示「待家長匯款」，不誤稱待審核或待財務核帳。公費配發與團 T 申請仍依原規則通知審核。
- 學校首頁與待辦事項增列「比賽服買斷｜待家長匯款」，點選進入現有的比賽服家長申請清單。匯款已回報、核帳完成、取消及已領取的紀錄不會列入此項。
- 待辦分來源載入：團服資料已回傳時即可顯示，不必等待出勤追蹤全部讀取完成。失敗仍保留原錯誤提示，不當作確認為零。
- 已存在但漏通知的申請，可在「團服與活動 → A 團比賽服 → 家長申請」按「補送幹部通知」。PATCH `SEND_STAFF_NOTICE` 僅同校管理員可使用，查核目前紀錄、版本與通知資格並留存稽核，不更改申請、金額、匯款或採購狀態。
- 獨立 LINE LAB 優先通知原已綁定的幹部多人群組；成功不再逐一發送或寄信。群組無法受理時改寄有效幹部的 Email，不改送個人 LINE。群組通知採同校、同申請與同群組的持久去重，補送不會重複已受理的群組通知；無法確認的結果保留待查。
- 通知不依賴幹部個人 LINE 綁定。老師、停用管理員與其他學校不列入備援收件者，群組訊息不附家長帳號或學生識別資料。

驗證涵蓋真實申請處理器及通知程式搭配儲存與通訊替身、買斷／公費／團 T 分流、原付款狀態不變、群組受理與 Email 備援、跨校與版本權限、補送去重、待辦計數／點選及分來源載入。沒有新增實際申請或發送真人測試通知。
