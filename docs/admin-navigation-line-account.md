# 後台導覽與個人 LINE 綁定整合（LINE LAB）

學校管理員底部分頁固定為「工作首頁／操作紀錄／平台設定」。待辦只保留在工作首頁，移除重複待辦頁與更多頁；舊 tasks 呼叫歸到首頁，舊 more 歸到平台設定。使用說明及重新查看入門引導在平台設定可直接開啟，首頁原有入門指引保留。家長與老師的導覽不變。

登出沿用原本頁首按鈕與登出流程，手機與桌面都在右上角；不新增另一套登出事件。手機品牌區為登出保留空間，按鈕至少 64×44px，底部分頁維持三等分並支援安全邊界。

LINE 通知中心提供「發送通知／群組與通知設定／我的 LINE 綁定」三個頁籤。移除上方開啟獨立 LINE 帳號頁的連結；個人狀態、確認綁定、取消、同步選單及解除綁定都在本頁處理。個人綁定與群組綁定資料互相獨立，管理他人的帳號仍屬帳號管理。

個人 LINE 帳號介面抽成共用面板，通知中心與原 line-account.html 共用原 API 與權限。家長、老師與舊書籤仍可使用原頁；不讀取收費專案或銀行資料。進入只讀取狀態，不自動綁定、解除或發送通知。

若須 LINE 授權，僅授權階段離開本頁，以最上層導向 LINE 避免 iframe 被拒絕。通知中心的同校管理員綁定可指定固定 returnTo=notification-center，伺服器存入原 OAuth 交易，成功或失敗返回通知中心我的綁定頁籤。只接受固定 enum，不接受自訂 URL；回呼 query 無法覆寫返回位置。原 state、cookie、nonce、PKCE、同校管理員及一次性交易檢查保留，原家長／老師返回路徑不變。

設定與個人綁定異動會使通知預覽失效，訊息草稿保留；未完成的操作期間避免切換頁籤。授權返回旗標處理後從網址清除，不改動權限或群組資料。財務核帳仍獨立且僅財務人員可操作。
