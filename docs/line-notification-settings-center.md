# LINE 群組與通知設定移至通知中心

學校後台以「LINE 通知中心」集中發送通知與管理群組。預設頁籤為「發送通知」，另一頁籤為「群組與通知設定」；切換保留未送出的訊息與對象，群組或通知設定異動會使原發送預覽失效，須重新預覽收件對象。

設定沿用原有 /api/line/settings API、學校隔離、管理員權限與綁定資料，不重建既有群組。幹部群組承接原一般待辦群組，學校群組承接原學生缺席通知群組。通知中心原有群組來源優先規則不改變。既有綁定直接顯示名稱與狀態；只有尚未綁定或使用者明確更換時才產生六位數綁定碼。

支援重要即時加每日摘要、只有即時、只有每日摘要與關閉待辦通知；缺席通知固定只在學生新標記缺席時通知，請假、遲到及重複儲存不發送。測試與解除綁定保留明確確認，未進行真實測試推播或解除既有綁定。

新面板須驗證本校管理員才可載入；即使公告功能尚未啟用或公告載入失敗，仍可開啟設定確認官方帳號狀態。綁定碼只保存在目前面板記憶體中，GET 輪詢不要求後端重送明碼；離開設定頁籤停止輪詢，學校／帳號切換後不顯示舊資料。

「更多 → 平台設定」移除重複的 LINE 設定、操作函式與自動讀取，保留 Email、網站品牌與其他設定。過期綁定碼的 LINE 回覆也改引導至「LINE 通知中心 → 群組與通知設定」。
