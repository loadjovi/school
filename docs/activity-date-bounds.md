# 活動區間日期選擇

- 快閃／校際交流／聯演的跨日活動：結束日期的最早可選日跟隨開始日期，允許同日，不可選較早日期。
- 期末聚餐等付費活動：日期時間區間與報名結束時間均跟隨對應的開始值；同日仍檢查時間順序。
- 免費演出／賽事公告：跨日結束日期沿用「晚於開始日期」規則，單日仍隱藏結束日期。
- 變更開始值、切換活動類型與單日／跨日模式、載入已儲存活動時，都會更新日期選擇器的最早可選值。隱藏、不適用的日期限制會移除。
- 原有結束值不會被靜默改寫；若早於新的開始值，原生欄位驗證與送出檢查會阻止儲存，要求管理員修正。
- 加練／寒暑訓目前逐日輸入上課日期，沒有開始／結束日期區間。現有日期與活動資料不會由本次更新批次修改，也不會發送通知。

驗證涵蓋未來日期、跨年、開始值變更／清空、報名同日的時間比較、載入既有活動、不同活動類型／單日跨日切換，以及既有免費公告與付費活動回歸。
