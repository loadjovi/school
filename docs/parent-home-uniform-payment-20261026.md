# 家長首頁團服待匯款提醒

學校核准自費團 T 後，家長原本需進入活動團服，再切至我的紀錄才看到收款資料。現在登入首頁最上方直接顯示待匯款筆數、對應學生、尺寸、件數與伺服器核定金額，按「查看匯款帳戶／回報末五碼」直接定位該筆表單。首頁不放完整收款帳號。

以既有 `/api/uniform-events/requests` 家長授權資料為準：僅核准後、金額明確且需要自費的有效團服訂單顯示提醒。待審、取消、已發放、公費、金額未確認及已核帳不催繳。已回報改顯示待財務核帳與無須重複匯款；財務確認後移除提醒。每筆各自列示金額，不以跨帳戶總計要求家長合併匯款。

家長每次回首頁重讀；頁面可見時每分鐘、重新切回頁面時更新。表單刷新會通知父頁重新讀取。非本頁 iframe 或不同來源的訊息被忽略；切換帳號／學校／角色與回首頁會讓舊查詢失效，避免延遲回應重新顯示舊付款狀態。讀取失敗顯示重試，清除舊催繳內容。

申請摘要與我的紀錄共用付款階段：已核准待匯款 → 已回報待財務核帳 → 已確認入帳等待採購。付款與採購 API、價格及核帳權限不變。特殊活動提醒維持在付款提醒後方；手機按鈕換行且至少 44px。

驗證：狀態分類、公費／取消排除、多子女金額、首頁順序、帳號與學校隔離、延遲回應、來源訊息限制、錯誤重試及指定訂單定位，另執行既有團 T 領用、採購與 LAB 隔離回歸。正式與 LAB 部署流程皆包含新測試。
