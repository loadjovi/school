# 團T、校外教學與期末聚餐：2026-10-11 需求確認

## 團T（T-shirt）
- 學生：每位首次免費一套，第二套起每套 NT$400；115 學年度儲備團全員與李沛臻尚未領用，其他既有團員已領第一套。
- 家長：擔任弦樂團幹部或志工者，**以家長身分**首次免費一套，後續加購 NT$400（暫依團T加購規則；若家長售價另定須確認）。
- 家長可能同時為幹部與志工、或關聯多名學生；以唯一 parentId 核對免費資格，不能因多角色、多子女重複領免費套數。
- 學生資訊顯示其關聯家長的團T資格／身分，但領用交易歸屬家長 ID；不以學生 ID 代替家長 ID。
- 建議欄位：schoolId、holderType(STUDENT/PARENT)、holderId、linkedStudentIds、parentRoles、size、freeUsedAt、issuedAt、quantity、paymentStatus、auditTrail。歷史匯入與實際發放需逐筆確認。

## 校外教學與期末聚餐費用
- 每筆基本報名：1 名弦樂團學生 + 1 名成人（家長）；額外成人、額外兒童需另列，且避免同家庭多位團員重複計算共同陪同成人。
- 校外教學：學生與首位成人均需付費；額外同行者依該活動費率。
- 期末聚餐：弦樂團學生免費但計入總人數／餐廳座位；首位成人需付費；額外同行者依該活動費率。
- 後台必須可設定各場活動的學生費用、首位成人費用、額外成人費用、額外兒童費用，並在確認旅行社／餐廳後**才鎖定並公布費率**；期末聚餐學生費固定為 0，不應允許填非零。
- 尚未定價時報名不能因費用未定而被視為失敗，應顯示「費用待公布」；活動報名與繳費分開。

## 報名及匯款雙確認（獨立狀態）
1. 家長確認報名，後端成功建立／更新有效報名紀錄才計入人數（學生、成人、額外兒童分項）。避免重複報名與家庭重複計算。
2. 後台核對報名人數、廠商、費用，確認後開放付款；只對已成功報名的家長顯示幹部指定收款帳戶、應繳金額、期限。
3. 家長匯款後填寫匯款日期、匯款金額、匯出帳戶末五碼或識別資訊並提交；狀態為「已回報匯款／待財務核帳」，**不得自動變成已繳費**。
4. 財務委員（專屬權限）查驗實際入帳後勾選「已核實收款」，記錄核對人、時間、金額、備註與稽核；才能顯示已繳費。
5. 若金額不符、找不到入帳或重複匯款，財務委員可標記異常，請家長補正；應保留更正歷程。

## 安全及驗收限制
- 收款銀行資料為敏感資訊：後端權限檢查，未報名／未開放付款者不可讀取；避免帳號資訊寫入公開設定或前端 bundle。
- 不應儲存完整匯出帳號，原則只收末五碼；後台只有財務角色可操作核帳，其他管理者權限需另議。
- tenant/schoolId 隔離、studentId/parentId 存取權、金額在後端計算、費率版本鎖定、異動稽核、併發／重複請求防護均為上線前必要條件。
- 目前 PR #22 僅有設定及基本申請 API，**尚未實作**家長報名確認 UI、費率鎖定、帳戶開放、匯款回報、財務核帳、家長團T領用；不可當作已完成。

## 家庭同行人數（2026-10-11 追加確認）
- 校外教學、期末聚餐均要求參與的弦樂團學生至少 1 人，**陪同成人至少 1 人**；允許 2 人以上大人。
- 家長端應從已綁定學生中勾選參加的團員（同家庭多位團員可一筆報名），另用下拉選單選擇陪同大人人數（1 起）及非弦樂團同行兒童人數（0 起）。
- 後台分別統計：弦樂團學生、成人、非團員兒童、合計；每一個人只計一次，不可依團員人數重複乘算陪同成人。
- 基本報名驗證：selectedStudentIds.length >= 1、adults >= 1、extraChildren >= 0；所有 selectedStudentIds 必須屬於目前家長授權關聯的學生，並以家庭／活動避免重複報名。
- 報名成功即納入統計；費用待廠商確認後才發布。期末聚餐團員學生免費、校外教學團員學生需付費，成人與非團員兒童各依活動費率計算。
- 目前 requests API 使用單一 studentId 且 adults 允許 0，**尚未符合本需求**；正式開放家長報名前必須修改 API 驗證及家庭報名資料結構。

## 家庭陪同成人最終確認
- 使用者確認：同一家庭有兩位或更多弦樂團學生參加，**只要至少一位家長／成人陪同即可**，不要求每位學生各配一位成人。
- 陪同成人按家庭實際參加人數計算一次；例：兩位團員＋一位家長＋一位非團員兒童＝4 人。
- 前端人數選單與後端報名驗證均採 `selectedStudentIds.length >= 1 && adults >= 1`，不採 `adults >= selectedStudentIds.length`。
